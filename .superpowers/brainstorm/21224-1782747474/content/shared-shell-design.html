Design section 1: shell behavior

The app gets one shared navigation shell after onboarding. Desktop keeps a persistent left sidebar. Narrow screens use a drawer opened from a small top bar. Both variants expose the same primary destinations: Home for the durable primary conversation and Memory for the memory management surface.
