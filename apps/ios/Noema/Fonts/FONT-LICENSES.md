# Noema fonts

These font files are shared by the native and web clients. They were sourced
from the Google Fonts repository at commit
`2796410152d4f9524b68ed46e69c1b60f8e0f7c3`:

- Bricolage Grotesque: `ofl/bricolagegrotesque`
- Hanken Grotesk: `ofl/hankengrotesk`
- JetBrains Mono: `ofl/jetbrainsmono`

Each family is distributed under the SIL Open Font License 1.1. The verbatim
license for each family is kept beside its font file.
