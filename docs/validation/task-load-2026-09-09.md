## Cause supported by source inspection

Both page queries request `pendingHumanInterventions`.
That path calls `pendingAdapterAuthentications`, which loads every connector definition and connection even when no authentication request needs a name.

- [Page queries](../../apps/web/src/graphql/tasksOperations.ts): both overview and detail include the intervention root.
- [Intervention resolver](../../internal/graphql/action_requests.go): also reloads full task details to obtain task attention.
- [Connector authentication resolver](../../internal/graphql/adapters.go): `pendingAdapterAuthentications` unconditionally calls `Snapshot`.
- [Connector snapshot](../../internal/adapter/service.go): `Snapshot` holds the shared service mutex while loading definitions and connections.
- [Definition loading](../../internal/adapter/files.go): `loadDefinitionAt` reads and compiles manifests, validates metadata, and hashes saved source files.

The shared lock can make overlapping page requests wait for each other.
This explains the observed pattern: approximately 0.5 seconds separately, versus 1.1 seconds for task details during page loading.
Lock contention is a source-supported inference. The exact wait duration was not sampled.
Repeated task-detail loading is another cost, but the measurements show that it is small here.

Additional requests returned 49 connector definitions in 2.09–8.02 seconds.
That query also builds connector views and reads OAuth state. Its duration cannot be assigned to the snapshot alone.
Approval actions alone took 29–259 ms in these later samples. Background activity and timing variation remained present.

## Next correction

First, skip the connector snapshot when no pending connector authentication request needs it.
When requests exist, resolve only their required names through the existing connector authority.
Keep approval data and credential boundaries intact.
Then measure the same page and isolated queries again.
If repeated definition compilation still dominates, address reuse in the existing connector authority.
