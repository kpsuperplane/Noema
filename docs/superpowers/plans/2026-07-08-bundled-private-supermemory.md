# Bundled Private Supermemory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Managed Supermemory uses a bundled/private sidecar endpoint instead of requiring a user-installed `supermemory-server` on a fixed visible port.

**Architecture:** Add a Supermemory binary resolver and private loopback endpoint allocator under `crates/noema-core/src/supermemory/`. The runtime host starts the sidecar, keeps the managed endpoint in memory, and injects a `SupermemoryConnection` into the daemon runtime so search and ingest use the private endpoint instead of persisted settings. GraphQL and the web Memory settings surface keep External URL editable while hiding managed-mode URL and port details.

**Tech Stack:** Rust, Tokio child process lifecycle, reqwest Supermemory client, rusqlite store schema, async-graphql schema/types, React + Apollo + Astryx + StyleX settings UI, Bun codegen/lint/build.

## Global Constraints

- No fork of Supermemory.
- No custom Supermemory protocol in this slice.
- No guarantee that managed mode uses no TCP listener at all; upstream Supermemory currently requires an HTTP listener.
- Bind target is loopback only, never `0.0.0.0`.
- Port is selected at runtime and is not the default fixed `6767` unless every private-port attempt fails and the explicit fallback path reports that fact.
- The chosen endpoint is kept in memory on the runtime host and injected into the Supermemory client boundary.
- SQLite stores readiness status and diagnostic errors, not the runtime managed endpoint.
- Managed Local does not show: Port input, Base URL input, or the runtime private endpoint.
- External URL keeps the base URL control and readiness check.
- Secrets never live in SQLite.
- Frontend tests are not required for this UI slice by current project instructions.
- Preserve unrelated dirty worktree changes.

```rust
//! Supermemory server binary resolution.

use std::{
    env,
    path::{Path, PathBuf},
};

use thiserror::Error;

pub const NOEMA_SUPERMEMORY_SERVER_ENV: &str = "NOEMA_SUPERMEMORY_SERVER";

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct SupermemoryServerBinary {
    pub path: PathBuf,
    pub source: SupermemoryBinarySource,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SupermemoryBinarySource {
    Environment,
    Bundled,
    Path,
}

#[derive(Debug, Clone)]
pub struct SupermemoryBinaryResolver {
    bundled_root: PathBuf,
    path_lookup_enabled: bool,
}

impl SupermemoryBinaryResolver {
    #[must_use]
    pub fn new(bundled_root: PathBuf, path_lookup_enabled: bool) -> Self {
        Self {
            bundled_root,
            path_lookup_enabled,
        }
    }

    pub fn default_for_paths(paths: &crate::NoemaPaths) -> Self {
        Self::new(default_bundled_root(paths), true)
    }

    pub fn resolve(&self) -> Result<SupermemoryServerBinary, SupermemoryBinaryError> {
        let env_path = env::var_os(NOEMA_SUPERMEMORY_SERVER_ENV).map(PathBuf::from);
        self.resolve_with_env(env_path)
    }

    pub fn resolve_with_env(
        &self,
        env_path: Option<PathBuf>,
    ) -> Result<SupermemoryServerBinary, SupermemoryBinaryError> {
        if let Some(path) = env_path {
            return executable_candidate(path, SupermemoryBinarySource::Environment);
        }

        let bundled = self.bundled_root.join(server_filename());
        if bundled.exists() {
            return executable_candidate(bundled, SupermemoryBinarySource::Bundled);
        }

        if self.path_lookup_enabled {
            if let Some(path) = lookup_path(server_filename()) {
                return executable_candidate(path, SupermemoryBinarySource::Path);
            }
        }

        Err(SupermemoryBinaryError::Missing)
    }
}

#[derive(Debug, Error)]
pub enum SupermemoryBinaryError {
    #[error("supermemory-server executable was not found")]
    Missing,
    #[error("supermemory-server candidate is not executable: {path}")]
    NotExecutable { path: PathBuf },
    #[error("supermemory-server candidate could not be inspected at {path}: {message}")]
    Io { path: PathBuf, message: String },
}

impl SupermemoryBinaryError {
    #[must_use]
    pub const fn sanitized_code(&self) -> &'static str {
        match self {
            Self::Missing => "supermemory_server_missing",
            Self::NotExecutable { .. } => "supermemory_server_not_executable",
            Self::Io { .. } => "supermemory_start_failed",
        }
    }

    #[must_use]
    pub const fn sanitized_message(&self) -> &'static str {
        match self {
            Self::Missing => "supermemory-server executable was not found",
            Self::NotExecutable { .. } => "supermemory-server executable is not runnable",
            Self::Io { .. } => "supermemory-server executable could not be inspected",
        }
    }
}

#[must_use]
pub fn server_filename() -> &'static str {
    if cfg!(windows) {
        "supermemory-server.exe"
    } else {
        "supermemory-server"
    }
}

fn default_bundled_root(paths: &crate::NoemaPaths) -> PathBuf {
    std::env::current_exe()
        .ok()
        .and_then(|path| path.parent().map(Path::to_path_buf))
        .unwrap_or_else(|| paths.supermemory_dir())
        .join("supermemory")
}

fn executable_candidate(
    path: PathBuf,
    source: SupermemoryBinarySource,
) -> Result<SupermemoryServerBinary, SupermemoryBinaryError> {
    let metadata = std::fs::metadata(&path).map_err(|error| SupermemoryBinaryError::Io {
        path: path.clone(),
        message: error.to_string(),
    })?;
    if !metadata.is_file() {
        return Err(SupermemoryBinaryError::NotExecutable { path });
    }
    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        if metadata.permissions().mode() & 0o111 == 0 {
            return Err(SupermemoryBinaryError::NotExecutable { path });
        }
    }
    Ok(SupermemoryServerBinary { path, source })
}

fn lookup_path(program: &str) -> Option<PathBuf> {
    let paths = env::var_os("PATH")?;
    env::split_paths(&paths)
        .map(|entry| entry.join(program))
        .find(|candidate| candidate.is_file())
}
```

//! Runtime-only Supermemory endpoint configuration.

use std::net::{Ipv4Addr, SocketAddrV4, TcpListener};

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct SupermemoryConnection {
    pub base_url: String,
    pub api_key: Option<String>,
}

impl SupermemoryConnection {
    #[must_use]
    pub fn new(base_url: String, api_key: Option<String>) -> Self {
        Self {
            base_url: base_url.trim_end_matches('/').to_string(),
            api_key,
        }
    }
}

pub fn allocate_loopback_port() -> Result<u16, std::io::Error> {
    for _ in 0..16 {
        let listener = TcpListener::bind(SocketAddrV4::new(Ipv4Addr::LOCALHOST, 0))?;
        let port = listener.local_addr()?.port();
        if port != 6767 {
            return Ok(port);
        }
    }
    Ok(6767)
}
