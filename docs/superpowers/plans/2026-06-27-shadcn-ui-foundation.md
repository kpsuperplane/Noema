# shadcn/ui Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adopt shadcn/ui as Noema's local web UI foundation while preserving the current GraphQL chat behavior and Noema-owned domain components.

**Architecture:** Configure Tailwind and shadcn/ui in the existing Vite React app, generate source-owned primitives under `src/components/ui`, then migrate the current app shell and chat surface to consume those primitives. Keep Noema domain components responsible for transcript semantics, memory rows, GraphQL replay, and live subscription state.

**Tech Stack:** React 19, Vite 7, Bun, Apollo Client, GraphQL subscriptions, shadcn/ui CLI, Tailwind CSS, Radix-backed shadcn components, lucide-react.

---

## Scope

This plan implements the first shadcn/ui foundation slice from `docs/superpowers/specs/2026-06-27-shadcn-ui-foundation-design.md`.

It does:

- Configure the existing Vite web app for shadcn/ui.
- Add a focused primitive set to `src/components/ui`.
- Introduce the `@/*` alias expected by shadcn/ui.
- Keep Noema's GraphQL and transcript data flow unchanged.
- Migrate the existing shell, onboarding, composer, status badges, and transcript frame to use the foundation.
- Add `MessageScroller` for chat scroll behavior without adopting AI SDK state ownership.
- Update durable project context to record the foundation decision.

It does not:

- Switch Noema to Vercel AI SDK.
- Replace Apollo Client.
- Change GraphQL operations, subscriptions, generated types, or backend Rust.
- Build memory detail, approval, tool, run, workspace, or multi-agent surfaces.
- Add a full visual redesign beyond adapting current UI to the new primitives.

    <div className="status-cluster" aria-label="Local status">
      <StatusPill tone={status?.localService === "RUNNING" ? "good" : "neutral"}>{localService}</StatusPill>
      <StatusPill tone={status?.memoryStorage === "READY" ? "good" : "neutral"}>{memory}</StatusPill>
      <StatusPill tone={socketState === "ready" ? "good" : socketState === "closed" ? "bad" : "neutral"}>
        {socket}
      </StatusPill>
      <StatusPill tone={agentStatus === "ERROR" || agentStatus === "closed" ? "bad" : "neutral"}>
        {agent}
      </StatusPill>
    </div>
  );
}

function StatusPill({ tone, children }: { tone: "good" | "bad" | "neutral"; children: React.ReactNode }) {
  return (
    <Badge
      variant="outline"
      className={cn(
        "status-pill",
        tone === "good" && "status-pill--good",
        tone === "bad" && "status-pill--bad"
      )}
    >
      {children}
    </Badge>
  );
}

function renderTranscriptEntry(

  expandedActivities: Set<string>,
  onToggleActivity: (id: string) => void
) {
  if (entry.type === "user") {
    return <Message role="user" name="You" text={entry.text} />;
  }

        item={entry.item}
        open={expandedActivities.has(entry.id)}

      />
    );

  }
  return <ErrorNotice message={entry.message} recoverable={entry.recoverable} />;
